Drop project images and videos here, then reference them by path in
data/project.js  (e.g.  src: "assets/hero-balcony.webp").

Suggested filenames — but any name works, the data file decides:

  hero-1.webp ... hero-4.webp    hero slider slides
  walkthrough.mp4 + .jpg poster  video slide
  about.webp                     the About section image
  master-plan.webp               master layout (renders blurred behind a CTA)
  unit-plan.webp                 unit layout   (renders blurred behind a CTA)
  amenity-gym.webp, amenity-pool.webp, ...
  gallery-1.webp ... gallery-6.webp
  visit-bg.jpg                   site-visit band background (set in css/styles.css)
  og-image.jpg                   1200x630 — WhatsApp/social share preview
  logo.png                       developer logo (optional; else a monogram shows)

Compress everything at squoosh.app before uploading. Target .webp under 200 KB.
Anything left unset in data/project.js renders a labelled placeholder tile, so
the site stays presentable until the real art arrives.
